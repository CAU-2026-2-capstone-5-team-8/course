# SnapSpot 코스 안내 페이지

SnapSpot에서 만든 공유 QR을 일반 카메라로 찍었을 때 열리는 페이지예요. 파일은 `index.html` 하나예요.

- 장소 정보는 주소의 `#` 뒤에 있어요. 브라우저는 이 부분을 서버로 보내지 않고, 페이지가 그 폰 안에서 풀어 보여 줘요.
- 이 저장소에는 사용자의 장소가 없어요. 외부 파일이나 글꼴도 불러오지 않아요.
- "카카오맵에서 보기"나 "걷는 길 보기"를 누르면 그때 그 장소만 카카오맵으로 넘어가요.
- 주소 형식은 `#1.` 뒤에 압축한 내용(base64url)이에요. 앱의 `core/ShareCode.kt`와 같아야 해요.
- **이 저장소를 지우거나 이름을 바꾸면 이미 만든 QR이 일반 카메라에서 열리지 않아요.**
