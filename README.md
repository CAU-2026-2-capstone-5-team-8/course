# SnapSpot 코스 안내 페이지

SnapSpot에서 만든 공유 QR을 일반 카메라로 찍었을 때 열리는 페이지예요. 우리가 쓴 파일은 `index.html` 하나예요.

- 장소 목록은 주소의 `#` 뒤에 있어요. 브라우저는 이 부분을 서버로 보내지 않고, 페이지가 그 폰 안에서 풀어 보여 줘요. 이 저장소에는 사용자의 장소가 없어요.
- 지도 그림은 OpenStreetMap에서 가져와요. 그래서 어느 동네를 보는지는 그쪽에서 알 수 있어요.
- "실제 걷는 길 그리기"를 누를 때만 장소의 좌표가 [FOSSGIS 길찾기 서버](https://routing.openstreetmap.de/about.html)로 보내지고, 그 서버의 기록에 남아요.
- "카카오맵에서 보기"나 "걷는 길 보기"를 누르면 그때 그 장소만 카카오맵으로 넘어가요.
- 주소 형식은 `#버전.내용`이에요. 내용은 압축한 글을 base64url로 적은 것이고, 버전 2는 검사 값이 있어 주소가 바뀌면 열리지 않아요. 앱의 `core/ShareCode.kt`와 같아야 해요.
- 지도를 그리는 [Leaflet](https://leafletjs.com) 1.9.4를 함께 넣었어요(`leaflet.js`, `leaflet.css`, BSD-2, `leaflet-LICENSE.txt`).
- **이 저장소를 지우거나 이름을 바꾸면 이미 만든 QR이 일반 카메라에서 열리지 않아요.**
